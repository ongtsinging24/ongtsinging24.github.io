CrowdStrike Falcon

公司電腦上那個 CSFalconService 能管控哪些事：擋程式、記錄行為、遠端開 shell、整台隔離、USB 管控。以一台實機（感測器 8.10）盤點哪些模組真的啟用、WSL 看得到多少，以及它和 Microsoft Defender for Endpoint 怎麼分工。

EDR
Endpoint Detection and Response，端點偵測與回應
NGAV

IOA
Indicator of Attack，攻擊行為特徵；相對於 IOC（Indicator of Compromise，入侵後留下的痕跡）
RTR

On-Demand Scan，手動或排程的檔案掃描
MDE

SOC

CID / AID
Customer ID（公司租戶）／Agent ID（這台電腦在後台的身分）

1它是什麼

Falcon 是 CrowdStrike 的雲端端點資安平台。本機只裝一個輕量感測器（sensor），負責收集行為與執行封鎖；判斷、關聯、保存都在 CrowdStrike 的雲端（Threat Graph）。公司的資安團隊從網頁後台（Falcon console）看告警、查記錄、下指令。

它是模組化授權：同一個感測器，公司買了哪些模組就開哪些功能，不用另外裝軟體。所以「本機有某個元件」不等於「功能有啟用」，要分開看。

2011　CrowdStrike 成立
主打雲端原生 EDR，不在本機放大型特徵碼庫
2024-07-19　全球大當機
一份有問題的內容更新（Channel File 291）讓約 850 萬台 Windows 藍屏。說明了一件事：感測器跑在核心層，權限與風險都在最底層
現在　Falcon 平台
EDR 之外擴充到身分保護、弱點管理、IT 自動化、雲端工作負載等模組

3這台實際啟用了什麼

以使用者權限（非管理員）從服務、驅動、登錄檔與安裝紀錄判斷：

項目狀態依據
Windows Sensor 8.10啟用服務執行中；與雲端連線旗標為 1
Device Control 7.40啟用CSDeviceControl 驅動執行中，且有政策登錄機碼
Firmware Analysis 7.14啟用CSFirmwareAnalysis 開機驅動執行中
ODS 掃描有政策OdsScan 登錄機碼存在
Falcon for IT已安裝目錄存在（無權限讀內容）
WSL 外掛未啟用DLL 存在，但 WSL 的外掛登錄區是空的
瀏覽器擴充未啟用有 native host 設定檔，但 Chrome 沒裝對應擴充
防火牆管理未見使用找不到 CrowdStrike 建立的防火牆規則
Windows 安全中心主要防毒Falcon 登記為啟用中的防毒；Defender 退為被動（第 7 節）
看不到的部分：防護政策開到多嚴、資料保留幾天、有沒有買真人值班服務，都在後台設定；本機日誌只記服務啟停，偵測資料不留在本機。

4能管控的事

歸納成三類：擋、記、遠端動手。第三類權限最大。

模組做什麼使用者會感受到的
Prevention（NGAV）執行前用機器學習判斷檔案；惡意就不讓執行並隔離下載的工具被隔離，跳出 Falcon 通知
Prevention（IOA）執行中依行為砍程序：讀 LSASS 抓密碼、注入其他程序、大量加密檔案、Office 開 PowerShell、混淆腳本某支腳本或巨集執行到一半被終止
腳本可見度PowerShell、VBScript 的實際執行內容送檢，混淆過也看得到原文平常感覺不到
EDR（Insight）全天候記錄行為，送雲端關聯分析平常感覺不到
RTRSOC 對這台開 SYSTEM 權限遠端 shell：列目錄、下載任何檔案、上傳檔案、讀登錄檔、砍程序、傾印記憶體、跑預寫腳本沒有任何提示，不需你同意
Network Containment一鍵整台斷網，只保留和 CrowdStrike 雲端的連線突然完全斷網，但 IT 仍連得到這台
Device Control依類別／廠商／型號／序號設定 USB 封鎖、唯讀或僅記錄；記錄寫進 USB 的檔案隨身碟不能寫，或插上就跳通知
Firmware Analysis開機時檢查 BIOS／UEFI 完整性感覺不到
ODS手動或排程掃描檔案某時段磁碟忙碌
Falcon for IT／Discover／Spotlight全機隊軟體清單、軟體實際使用情形、帳號盤點、弱點評估；可批次查詢「哪幾台裝了某軟體」並執行修補IT 來信要求移除某軟體
OverWatch／Falcon CompleteCrowdStrike 自己的分析師 24 小時主動搜捕（需另購）感覺不到；有事時資安單位直接找你
重點：RTR 是整套裡權限最大的功能。它不是只看記錄，而是能直接從你電腦上拿走任何檔案，包括 WSL 的整顆虛擬磁碟（ext4.vhdx 就是 C 槽上的一個檔案）。

5它收集什麼、IT 看得到什麼

類別看得到嗎說明
啟動了哪些程式看得到完整父子關係、路徑、雜湊值、執行帳號
完整命令列看得到參數原文；寫在參數裡的 token、密碼都會被記下
網路連線看得到哪個程序連到哪個 IP、port
DNS 查詢看得到哪個程序查了哪些網域
檔案寫入看得到重點是執行檔、腳本、壓縮檔、寫到 USB 的檔案；不是每個文件存檔都記
登錄檔、排程、服務看得到開機自啟動相關的變更
登入事件看得到登入、解鎖、RDP
檔案內容視情況平常不上傳；可疑檔案或 RTR 主動取檔時才拿到
螢幕畫面、截圖不收Falcon 不是側錄軟體（公司若另裝 DLP 則另當別論）
鍵盤輸入不收記的是「啟動程式」，不是「你打的每個字」
HTTPS 內容不收只看得到 IP、port、DNS，不解密
瀏覽網頁內容目前不收瀏覽器擴充未安裝

資料保存期依授權而定，常見為 7 到 90 天。

6WSL 看得到多少

Falcon 8.x 隨附 WSL 外掛（cswsl*.dll）。WSL 2 提供官方外掛介面，資安廠商可以藉此看見 WSL 裡的 Linux 程序。在這台電腦上，外掛檔案存在，但沒有註冊進 WSL：

目前狀態說明
WSL 內的 Linux 程序與指令看不到例如在 WSL 裡跑的 python3 xxx.py
wsl.exe、vmmemWSL看得到Windows 端的程序
寫進 /mnt/c 的檔案看得到從 Windows 看就是一般的檔案寫入
WSL 的 DNS、網路部分經 Windows 解析與 NAT 出去，可能被記錄，但對應不到是哪個 Linux 程序
WSL 虛擬磁碟整顆可取走RTR 能下載 ext4.vhdx
隨時可能改變：IT 只要在後台改政策就能啟用 WSL 外掛，本機不會有任何通知。不要把「目前看不到」當成「WSL 是私人空間」。

7和 Defender for Endpoint 並存

這台同時跑 Falcon 和 MDE。Windows 同一時間只會有一個「主要防毒」，另一個退到被動：

CrowdStrike FalconMicrosoft Defender
安全中心登記啟用中的主要防毒被動
Defender 執行模式—EDR Block Mode：防毒被動，但 EDR 發現惡意時仍可出手封鎖
EDR 遙測完整完整（兩邊各送一份到各自的雲端）
防篡改啟用啟用

所以你的每一個程序啟動、每一條連線，會被兩家廠商各記錄一次。兩套並存常見於換約過渡期，或公司刻意讓 Microsoft 的 DLP／弱點管理與 CrowdStrike 的防護互補。MDE 的部分詳見 Defender for Endpoint 那篇。

8自己查狀態的指令

以下都不需管理員權限（PowerShell）。從 WSL 呼叫時用完整路徑 /mnt/c/Windows/System32/WindowsPowerShell/v1.0/powershell.exe，並先 cd /mnt/c。

# 1. 服務與各元件版本
Get-Service CSFalconService
Get-ChildItem 'C:\Program Files\CrowdStrike\*.exe' |
  % { '{0,-34} {1}' -f $_.Name, $_.VersionInfo.FileVersion }

# 2. 已安裝的 CrowdStrike 模組（含隱藏的系統元件）
Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\* |
  ? DisplayName -match 'CrowdStrike' | Select DisplayName, DisplayVersion, InstallDate

# 3. 執行中的 CrowdStrike 驅動（判斷 Device Control／Firmware 有沒有開）
Get-CimInstance Win32_SystemDriver | ? Name -match '^CS' |
  Select Name, State, StartMode

# 4. 和雲端是否連線
(Get-ItemProperty HKLM:\SYSTEM\CurrentControlSet\Services\CSAgent\Sim).CloudConnected

# 5. WSL 外掛有沒有註冊（空的＝未啟用）
Get-ItemProperty HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Lxss\Plugins

# 6. 誰是主要防毒、Defender 的執行模式
Get-CimInstance -Namespace root/SecurityCenter2 -ClassName AntivirusProduct |
  Select displayName, productState
(Get-MpComputerStatus).AMRunningMode

# 7. 感測器本機日誌（只有服務啟停）
Get-WinEvent -LogName 'CrowdStrike-Falcon Sensor-CSFalconService/Operational' -MaxEvents 20

AID／CID 等識別資訊存在受保護的登錄機碼，一般使用者讀不到；需要時由 IT 從後台查。

9遇到問題怎麼辦

狀況建議
程式被擋，跳出 Falcon 通知記下時間、程式路徑與通知內容，找 IT 申請例外。不要改名、換路徑或重新編譯再試，繞過行為本身就是 IOA 的告警條件
開發工具、爬蟲、測試腳本被誤判常見於自己編譯的執行檔、打包成 exe 的 Python、注入或 hook 類工具。附上原始碼位置和用途向 IT 申請排除
突然整台斷網，只剩某些服務能連可能被 Network Containment 了，代表 SOC 正在調查。直接聯絡 IT，不要自己重灌
隨身碟不能寫入Device Control 政策。走公司的 USB 申請流程
想關掉它不行，也不應該。防篡改保護會擋下，嘗試本身會被記錄並告警
重點整理：Falcon 是跑在核心層的雲端 EDR。它擋惡意檔案與攻擊行為，記錄每個程序的命令列、網路與 DNS，也能讓資安人員以 SYSTEM 權限遠端取檔、整台隔離。它不錄畫面、不記鍵盤、不解 HTTPS。這台的 WSL 外掛目前未啟用，但隨時可能被打開；WSL 的虛擬磁碟一樣能被整顆取走。
