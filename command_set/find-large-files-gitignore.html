搜尋大於 20MB 的檔案，並排除於 Git 版控

在 OpenWrt 分析資料目錄中找出大檔，加入 .gitignore，並處理已被追蹤的大檔。

ojy@e67-4b1:~/sdk/openwrt/sd9_openwrt_24.10/data_to_analyze$

縮寫說明

MB
Megabyte，十進位 1,000,000 bytes
MiB
Mebibyte，二進位 1,048,576 bytes；find -size 的 M 單位即為 MiB
NUL
空字元（\0）；-print0 / xargs -0 用它分隔檔名，可安全處理含空白的路徑

1搜尋大檔（排除 .git）

-path ./.git -prune 讓 find 跳過 .git 目錄，避免把 Git 物件檔也列出來。

find . -path ./.git -prune -o -type f -size +20M -print
-size +20M 以 MiB 為單位、無條件進位比較，實際上會找出大於 20 MiB（20,971,520 bytes）的檔案。若要以十進位 20MB 為界，改用 -size +20000000c。

2同時顯示檔案大小

依大小由小到大排序，方便確認哪些是主要的佔用者。

find . -path ./.git -prune -o -type f -size +20M -exec du -h {} + | sort -h

3加入 .gitignore

-printf '%P\n' 會去掉路徑開頭的 ./，輸出格式可直接寫入 .gitignore。

find . -path ./.git -prune -o -type f -size +20M -printf '%P\n' >> .gitignore
sort -u .gitignore -o .gitignore   # 去除重複
sort -u 會打亂原本的行序。若 .gitignore 中有 !pattern 這類依賴順序的規則，改用下面的寫法，去重時保留原順序。 
awk '!seen[$0]++' .gitignore > .gitignore.tmp && mv .gitignore.tmp .gitignore

4移除已被追蹤的大檔

已經 git add 或 commit 過的檔案，加進 .gitignore 後仍會被追蹤。以下指令只從索引移除，工作目錄中的檔案會保留。

find . -path ./.git -prune -o -type f -size +20M -print0 | xargs -0 git rm --cached --ignore-unmatch

之後 commit 這次的變更，Git 就不再追蹤這些檔案：

git add .gitignore
git commit -m "Ignore files larger than 20MB"
git rm --cached 只影響之後的 commit。若大檔已存在於歷史紀錄中，repo 體積不會因此變小；需要清除歷史時，可使用 git filter-repo。

5預防：以副檔名規則排除

比起逐一列檔名，用副檔名規則可以一次排除日後新增的同類大檔。例如目錄中的 WQCAP-7310.gz（約 63MB）就會直接被排除。

# .gitignore
*.gz
*.pcap
*.pcapng
*.bin
*.tar
*.tgz
